## Brand & Style

This design system delivers a high-density, mission-critical Arabic-first enterprise dashboard engineered for modern logistics hubs, automated fulfillment centers, and deep-tier warehouse management. The aesthetic merges precision engineering with high-contrast tactical legibility. It rejects commercial retail conventions and superficial glows in favor of focused utility, spatial clarity, and authoritative enterprise ergonomics.

### Design Principles
- **Logistical Clarity First:** Every visual affordance prioritizes data density, inventory states, and zero-error scanning. Units, SKUs, bin coordinates, and status tokens supersede decorative flair.
- **RTL-Native Ergonomics:** Layouts are architected strictly right-to-left. Primary visual anchors, breadcrumbs, hierarchy trunks, and status indicators orient from the right, directing visual flow naturally along natural Arabic reading vectors.
- **Controlled Luminescence:** Surface elevation relies on calibrated tonal stepping and fine micro-borders (`#1C3A60`) rather than heavy drop shadows, minimizing optical fatigue during continuous 8-hour operator shifts.
- **Zero Ambiguity Operational States:** Quantitative thresholds (Stockout, Low, Allocated, Reserved, On-Hand) are anchored to rigorous, non-financial semantic colors to trigger immediate operator instinct.

## Colors

The palette utilizes a layered deep-navy foundation built explicitly for sustained low-light and warehouse ambient screen viewing. High-contrast cool primaries cut through deep surfaces to guide immediate operational action.

### Palette Architecture
- **Canvas Base (`#071426`):** The primary view canvas for entire viewport backgrounds.
- **Sub-Canvas / Navigation Canvas (`#0B1D35`):** Structural side navigation bars, collapsible utility sidebars, and sticky subheaders.
- **Surface Elevation (`#102947`):** High-density cards, operational tables, modal dialogs, and slide-over drawers.
- **Micro-Borders (`#1C3A60`):** Precise 1px boundaries establishing structural separation without visual weight.
- **Primary Operational (`#1677FF`):** Action targets, primary controls, focused states, and selected navigation nodes.
- **Secondary Telemetry (`#20C5E8`):** Allocated stock badges, transfer indicators, automated picking telemetry, and cross-docking states.
- **Semantic Indicators:**
  - **Success / In-Stock (`#10B981`):** Optimal inventory counts, completed picking tasks, verified manifests.
  - **Warning / Reserve Alert (`#F59E0B`):** Reorder cycle thresholds, staging bottleneck alerts, pending cycle counts.
  - **Critical / Stockout (`#EF4444`):** Zero physical balance, damaged pallets, quarantined stock, critical SKU depletion.
- **Typography Tiers:**
  - **Primary High-Contrast (`#FFFFFF`):** High-priority values, item titles, critical numerical measurements.
  - **Secondary Slated (`#8FA6C3`):** Metadata labels, SKU codes, rack-shelf-bin coordinates, table column headers.

## Typography

Typography centers on **IBM Plex Sans Arabic** for its disciplined, geometric Naskh structure, open counters, and exceptional clarity when displaying both Arabic script and Latin alphanumeric strings (such as SKU identifiers and barcoded coordinates).

### Rules of Engagement
- **RTL Baseline:** Every text element must render `direction: rtl` with a default `text-align: right`. 
- **Bilingual SKU & Code Display:** SKU codes, serialized tracking numbers, and warehouse coordinate strings (e.g., `WH-04-A-12`) utilize the `data-mono` role with `direction: ltr` and inline containment to ensure strict non-reversing character sequencing inside Arabic sentences.
- **Tabular Figures:** All numeric displays (stock balances, allocated quantities, row numbers) mandate the CSS property `font-variant-numeric: tabular-nums` to ensure vertical alignment across data grid columns.
- **Line Heights:** Arabic typography requires expanded vertical leading compared to Latin typography to prevent diacritic clipping; minimum body line-height ratio is maintained at 1.55x.

## Layout & Spacing

The layout model implements a structured, fluid-responsive multi-panel grid system calibrated for high data density across hand-held scanning tablets, terminal docks, and wide-screen logistics control center monitors.

### Layout Philosophy
- **RTL Split-View Architecture:** The primary permanent navigation rail sits anchored to the right viewport border (`width: 260px` desktop, collapsible to `72px`). The work area expands fluidly to fill the remaining horizontal space.
- **Grid Structure:** 12-column responsive fluid grid utilizing `gutter-desktop` (24px) on viewports above 1280px, dropping to `gutter` (16px) on tablet interfaces (768px - 1024px).
- **Container Hierarchy:** Inner workspace margins maintain `margin-desktop` (32px) to frame complex multi-level data tables without viewport edge collisions.
- **Form Factor Breakpoints:**
  - **Handheld / Mobile (≤ 767px):** Sidebars collapse into an off-canvas drawer opening from the right edge. Metric cards collapse to single-column full-width. Data tables default to swipeable cards.
  - **Warehouse Tablet (768px - 1199px):** 2-column metric cards, condensed 8-column layout, responsive table columns with horizontal scroll and fixed right SKU/Product column.
  - **Control Station Desktop (≥ 1200px):** 4-column KPI cards, full 12-column data views, side-by-side location bin mapping panels.

## Elevation & Depth

Visual hierarchy does not rely on heavy blurs or artificial dropshadows. Depth is articulated purely through calculated **tonal layering** and **luminescent micro-borders**.

### Surface Hierarchy
1. **Base Floor (Level 0):** `#071426` — Entire background canvas. No borders.
2. **Structural Paneling (Level 1):** `#0B1D35` — Navigation sidebars, secondary toolbars, pinned table headers. Separated from base via a continuous 1px `#1C3A60` border along the inner edge.
3. **Operational Containers (Level 2):** `#102947` — Data cards, inventory listing tables, batch processing containers. Framed with a 1px solid border of `#1C3A60`.
4. **Floating Overlays & Contextual Sheets (Level 3):** `#133256` — Modal dialogs, pallet detail flyouts, batch selection toasts. Elevated using a sharp 1px border of `#264D7E` combined with an ambient, deep-tinted occlusion: `0 12px 32px -4px rgba(3, 8, 16, 0.75)`.

### Focus and State Elevations
Active or selected rows and interactive panels shed surface borders in favor of an inner accent outline: `box-shadow: inset 0 0 0 1px #1677FF`. Hovering over interactive card blocks translates the border from `#1C3A60` to `#2A5384` with zero displacement.

## Shapes

The design system adopts a balanced geometry (`roundedness: 2`) to temper mechanical enterprise density with modern, refined software contours.

### Corner Radius Mapping
- **Standard Controls (`0.5rem` / `8px`):** Input fields, standard buttons, dropdown selectors, SKU tags, and tab navigation pills.
- **Card & Data Containers (`1rem` / `16px`):** Metric panels, table containers, warehouse aisle overview cards.
- **Modals & Slide-outs (`1.5rem` / `24px`):** Large inventory reassignment modals, pallet inspection sheets.
- **Indicators & Micro-Badges (`9999px`):** Status indicator dots, quantitative tag counters, binary stock presence pills.

- **Primary:** Solid `#1677FF` background, `#FFFFFF` text, `border-radius: 0.5rem`, padding `0.625rem 1.25rem`. Hover: `#2F86FF`. Active: `#0E60D4`. Focus: 2px ring offset `#071426`, ring color `#20C5E8`.
- **Secondary:** Surface `#102947`, border 1px solid `#1C3A60`, text `#FFFFFF`. Hover: border `#2A5384`, background `#143358`.
- **Danger (Quarantine / Write-off):** Surface `#2A161E`, border 1px solid `#EF4444`/50, text `#EF4444`. Hover: background `#3B1A26`.
- **Icon Placement:** Icons placed to the right of text for forward navigation/actions in RTL; to the left for back actions.

- **Aisle / Bin Coordinate Chip:** Background `#0B1D35`, border `1px solid #1C3A60`, text `#8FA6C3`, font `data-mono`.

### Data Tables (The Core Workhorse)

- **Columns Structure:**
